{% comment %} Global media kit — one component, loaded on every page (from base.html and the admin layout). Three cooperating pieces, all vanilla JS, no dependencies: 1. LIGHTBOX — click any [data-media] element to open the file at full size in an overlay (image / video / document) with a close button, Esc, click-outside, and ←/→ to move through the group it belongs to. Nothing opens in a new tab any more. 2. MEDIA GRID — `.media-grid[data-count=N]` lays attachments out like a social network: 1 big, 2 side-by-side, 3 (one tall + two), 4-up, and a "+N more" tile beyond four. Used by both the wall and the chat. 3. DROPZONE — progressively enhances any `.mediazone` (a wrapper around a real ) into a drag-and-drop area with live thumbnail previews, matching the Social theme's dropzone look/icons. The underlying still carries the files, so normal form/FormData submission just works. Reusable helper `window.OrgMedia.grid(attachments, opts)` builds the grid HTML from a list of {url, kind, name} — the chat uses it to render messages client-side. {% endcomment %} {% load static %}
