# ----------------------------------------------------------
# Production web server (Railway / any container host)
# ----------------------------------------------------------
# `runserver` is a development server and must never face the internet. Gunicorn
# is the process manager for a real deployment: it supervises, restarts and load-
# balances the workers, and binds the $PORT the platform hands the container.
#
# Gunicorn does not speak ASGI on its own, and this project IS ASGI — Channels
# carries live chat and notification push over WebSockets (config/asgi.py). So
# run it against config.asgi with a uvicorn worker class, never config.wsgi: the
# WSGI path serves ordinary HTTP perfectly well and then drops every WebSocket
# handshake, which surfaces as chat stuck on "connecting…" rather than as an
# error anyone can find.
#
#   gunicorn config.asgi:application \
#       -k uvicorn_worker.UvicornWorker -b 0.0.0.0:$PORT --workers 3
#
# uvicorn-worker is the maintained home of that worker class; the in-tree
# uvicorn.workers.UvicornWorker is deprecated. daphne (above) stays for the
# WebSocket-aware `runserver` in development; it is not used in production here.
gunicorn>=26.2,<27.0            # Process manager + HTTP front end for the app server
whitenoise[brotli]>=6.12,<7.0   # Serves /static/ from the app process (no nginx on Render's free tier)
uvicorn[standard]>=0.52,<0.53   #   └─ ASGI worker (uvloop, httptools, websockets)
uvicorn-worker>=0.4,<0.5        #   └─ gunicorn worker class for uvicorn (-k uvicorn_worker.UvicornWorker)


# ==========================================================
# EXTERNAL ACCOUNTS / SERVICES TO CONNECT
# ==========================================================
# `pip install -r requirements.txt` only installs the Python libraries. The
# accounts / services below also have to be set up (mostly via the project .env
# — copy .env.example to .env first). REQUIRED ones are marked; the rest are
# optional and have safe development defaults so the project still runs without them.
#
# ----------------------------------------------------------------------------
# 1. PostgreSQL  —  REQUIRED  (the primary database, Django "default")
# ----------------------------------------------------------------------------
#   a. Install & start PostgreSQL (or use a managed instance).
#   b. Create the database + a user:
#        createdb united_church_school_db
#        createuser -P ucs_lms          # then GRANT it on the DB
#   c. In .env set:  POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD,
#                    POSTGRES_HOST (default 127.0.0.1), POSTGRES_PORT (default 5432)
#   d. Apply migrations:   python manage.py migrate
#
# ----------------------------------------------------------------------------
# 2. MySQL  —  OPTIONAL, AND OFF BY DEFAULT  (DR replica, Django "backup")
# ----------------------------------------------------------------------------
#   DATABASES['backup'] is commented out in config/settings.py, so out of the box
#   there is no MySQL connection and no driver to install. To enable it:
#   a. Create a MySQL database (utf8mb4) + user.
#   b. Uncomment the 'backup' block in config/settings.py.
#   c. In .env set:  MYSQL_DB, MYSQL_USER, MYSQL_PASSWORD, MYSQL_HOST, MYSQL_PORT
#   d. Install a driver — see the Databases section above (PyMySQL or mysqlclient).
#   e. Keep its schema in sync:   python manage.py migrate --database=backup
#   (Skip entirely if you don't want a DR copy — nothing reads from it implicitly.
#    .admin_wipe_and_create.py wipes and migrates every alias it finds in
#    DATABASES, so enabling this means the reset touches MySQL too.)
#
# ----------------------------------------------------------------------------
# 3. Redis  —  OPTIONAL  (cache backend; future: real-time chat/notifications)
# ----------------------------------------------------------------------------
#   a. Install & run Redis (`redis-server`) or use a managed instance.
#   b. In .env set:  USE_REDIS=true   and   REDIS_URL=redis://127.0.0.1:6379/1
#   (Left off → Django uses an in-memory cache; everything still works.)
#
# ----------------------------------------------------------------------------
# 4. SMTP e-mail account  —  REQUIRED FOR REAL E-MAIL  (verification, password
#    reset, notifications, announcements). Default backend just prints to console.
# ----------------------------------------------------------------------------
#   a. Get SMTP credentials from a provider — e.g. Gmail (create an "App password"),
#      SendGrid, Mailgun, Amazon SES, Postmark, …
#   b. In .env set:
#        EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
#        EMAIL_HOST=smtp.your-provider.com
#        EMAIL_PORT=587
#        EMAIL_HOST_USER=your-smtp-username
#        EMAIL_HOST_PASSWORD=your-smtp-password-or-app-password
#        EMAIL_USE_TLS=true            # (or EMAIL_USE_SSL=true on port 465)
#        DEFAULT_FROM_EMAIL="United Church School <no-reply@ucs.org.za>"
#   c. To require e-mail confirmation on signup:  ACCOUNT_EMAIL_VERIFICATION=mandatory
#   (Branded HTML e-mails are in apps/communication/templates/communication/email/
#    and templates/account/email/; their wording/brand comes from .strings.json.)
#
# ----------------------------------------------------------------------------
# 5. Google & Facebook OAuth  —  OPTIONAL  (social login via django-allauth)
# ----------------------------------------------------------------------------
#   a. Create an OAuth app:
#        Google    → https://console.cloud.google.com/  (OAuth client ID, type "Web")
#        Facebook  → https://developers.facebook.com/    (Facebook Login product)
#      Authorised redirect URIs:
#        https://YOURDOMAIN/accounts/google/login/callback/
#        https://YOURDOMAIN/accounts/facebook/login/callback/
#   b. In the Django admin → "Sites": set the domain to your real domain.
#   c. In the Django admin → "Social applications": add one per provider with the
#      Client id + Secret key, and attach it to the Site.
#   (Until configured, e-mail/password login still works; the social buttons just
#    won't function.)
#
# ----------------------------------------------------------------------------
# 6. Jitsi Meet  —  OPTIONAL  (video/audio calls & class sessions)
# ----------------------------------------------------------------------------
#   Default uses the free public server (https://meet.jit.si) — no signup needed.
#   For privacy / full end-to-end-encryption control, deploy your own Jitsi and set:
#        JITSI_BASE_URL=https://meet.your-domain.com
#
# ----------------------------------------------------------------------------
# 7. Anthropic (Claude)  —  OPTIONAL  (admin AI assistant + AI authoring)
# ----------------------------------------------------------------------------
#   The `anthropic` package above is already installed; the feature stays dormant
#   until it has a key. To switch it on, in .env set:
#        ADMIN_AI_ENABLED=true
#        ANTHROPIC_API_KEY=sk-ant-...            # console.anthropic.com
#        ADMIN_AI_MODEL=claude-opus-4-8          # optional; this is the default
#   (No key → /assistant/chat/ reports "not configured" and AI authoring refuses
#    politely. Nothing else is affected.)
#   The old CrewAI + Ollama "ask about this page" widget is retired; its
#   AI_ASSISTANT_ENABLED / AI_LLM_* settings still exist in config/settings.py but
#   no longer drive anything, and CrewAI is not installed.
#
# ----------------------------------------------------------------------------
# 8. Django superuser  —  REQUIRED  (to reach /admin/)
# ----------------------------------------------------------------------------
#   .admin_wipe_and_create.py creates it for you, along with the other three base
#   accounts (all verified, all on the same password):
#        admin@ucs.org.za      superuser + staff
#        educator@ucs.org.za
#        student@ucs.org.za
#        parent@ucs.org.za     linked to the student
#   For a non-destructive setup instead:   python manage.py createsuperuser
#
# Also: set SECRET_KEY (a long random string) and ALLOWED_HOSTS in .env before
# any non-local deployment, and DEBUG=False.
# ==========================================================
