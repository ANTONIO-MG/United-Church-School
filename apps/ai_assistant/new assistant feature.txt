Yes, you can run all of those agents locally with CrewAI. The trick is pairing CrewAI with local models via Ollama + local tools for transcription, file reading, etc. No Google/ChatGPT API needed.

Here’s a refined CrewAI system built exactly for “take video/audio/PDF → summarize → extract actions → create tasks”:

2. Refined Agent Roles for CrewAI

CrewAI works best when each agent has 1 job + specific tools. Here’s how to define them:

from crewai import Agent, Task, Crew, LLM
from crewai_tools import FileReadTool, DirectoryReadTool

# Local LLM via Ollama
llm = LLM(model="ollama/llama3.1:8b-instruct", temperature=0.1)

# 1. Transcriber Agent
transcriber = Agent(
    role="Transcriber",
    goal="Convert audio/video to accurate text transcripts",
    backstory="Expert at speech-to-text using Whisper. Handles accents and noise.",
    tools=[AudioTranscribeTool()], # custom tool using faster-whisper
    llm=llm,
    verbose=True
)

# 2. Researcher/Reader Agent  
researcher = Agent(
    role="Document Researcher",
    goal="Extract and understand content from PDFs, docs, transcripts",
    backstory="Meticulous reader who never misses key details in documents",
    tools=[FileReadTool(), DirectoryReadTool(), PDFSearchTool()],
    llm=llm
)

# 3. Explainer/Summarizer Agent
summarizer = Agent(
    role="Explainer & Summarizer",
    goal="Create clear summaries, study guides, and explanations from source material",
    backstory="Teacher who can break down complex topics into simple bullet points",
    llm=llm
)

# 4. Action Extractor Agent
action_extractor = Agent(
    role="Action Item Extractor",
    goal="Identify all tasks, deadlines, decisions, and follow-ups from the content",
    backstory="Project manager who spots every actionable item and who owns it",
    llm=llm,
    output_format="JSON list with: task, owner, deadline, priority"
)

# 5. Planner Agent
planner = Agent(
    role="Planner",
    goal="Turn action items into scheduled plans and calendar events",
    backstory="Organized planner who avoids scheduling conflicts",
    tools=[CalendarTool()], # custom tool for Google Cal or local cal
    llm=llm
)

# 6. Task Creator Agent
task_creator = Agent(
    role="Task Creator & Executor",
    goal="Create tasks, send emails, generate invoices, set reminders",
    backstory="Operations assistant who executes tasks without being asked twice",
    tools=[EmailTool(), TaskManagerTool(), InvoiceGeneratorTool()],
    llm=llm
)

3. Extra Agents to Make This Actually Work Well

You’ll want these 2 to avoid headaches:

*7. QA/Validator Agent*  
Role: Check that actions are realistic, deadlines make sense, no duplicate tasks  
Why: LLMs hallucinate tasks. This agent catches “send email to null@null.com” before it fires.

*8. Router/Coordinator Agent*  
Role: Decide which agent runs next based on file type. If user uploads MP4 → send to Transcriber first. If PDF → skip straight to Researcher.  
Why: Stops you from wasting tokens transcribing a PDF.

4. Full Workflow for “Video → Actions → Tasks”

# Define tasks in order
transcribe_task = Task(
    description="Transcribe the uploaded audio/video file at {file_path} to text",
    agent=transcriber,
    output_file="transcript.txt"
)

read_task = Task(
    description="Read and extract key content from {file_path} or transcript.txt",
    agent=researcher,
    context=[transcribe_task] # only runs if transcribe_task ran
)

summarize_task = Task(
    description="Create a 5-bullet summary and 3 key takeaways from the content",
    agent=summarizer,
    context=[read_task],
    output_file="summary.md"
)

extract_actions_task = Task(
    description="List all actionable items, tasks, deadlines, and follow-ups from the content",
    agent=action_extractor,
    context=[read_task],
    output_file="actions.json"
)

plan_task = Task(
    description="Convert actions.json into scheduled calendar events. Avoid conflicts.",
    agent=planner,
    context=[extract_actions_task]
)

execute_task = Task(
    description="Execute the planned actions: create tasks, send emails, generate invoices",
    agent=task_creator,
    context=[plan_task]
)

# Run the crew
crew = Crew(
    agents=[transcriber, researcher, summarizer, action_extractor, planner, task_creator],
    tasks=[transcribe_task, read_task, summarize_task, extract_actions_task, plan_task, execute_task],
    process="sequential" # run in order
)

result = crew.kickoff(inputs={"file_path": "/path/to/uploaded/video.mp4"})

5. Local Tools You Need to Build

CrewAI doesn’t ship with these, but they’re easy:

1. *AudioTranscribeTool*: Wrap `faster-whisper` for local STT

from faster_whisper import WhisperModel
model = WhisperModel("base", device="cpu") # or "cuda" if you have GPU

class AudioTranscribeTool(BaseTool):
    def _run(self, file_path: str) -> str:
        segments, _ = model.transcribe(file_path)
        return " ".join([seg.text for seg in segments])

2. *CalendarTool*: Use `ics` library for local .ics files, or Google Calendar API
3. *EmailTool*: Use Python `smtplib` to send from your server
4. *InvoiceGeneratorTool*: Use `weasyprint` + HTML template to make PDFs

6. Running Everything Locally

*Hardware needs:*
- 16GB RAM minimum for `llama3.1:8b`
- GPU strongly recommended for Whisper transcription speed
- CPU works but 10min video = ∼5min to transcribe on CPU

*Stack:*
1. `ollama serve` to run LLM locally
2. Django for file upload + to kick off Crew
3. Celery for running Crew tasks async so your Django doesn’t hang
4. SQLite/Postgres to store results + created tasks
